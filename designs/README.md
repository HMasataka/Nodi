# Nodi のUIデザイン

`nodi.nodi` をNodiで開く。1440×960pxの同じエディタを、操作前後の12状態で並べている。

## 操作の流れ

- **01 → 02 → 03**：右の余白入力から共通値を選択し、「共通値を編集」で左のアセットと参照元の編集へ移る。適用・キャンセルを用意する。
- **03 → 04**：「共通値を削除」で使用箇所と直接値への変換を確認する。削除・キャンセルを用意する。
- **01 → 05 → 06**：左のアセットタブからコンポーネントを選択して配置。右がインスタンスの上書き欄へ変わる。「参照元」で定義へ戻り、「元に戻す」で文言の上書きを解除する。
- **01 → 07 → 08**：塗りの入力から共通色を選択。「パレットで編集」で左の色一覧と色編集を開く。
- **09**：3要素の選択が左の選択行、キャンバスの3つの枠、右の選択数に対応する。横間隔24pxはキャンバスの2つの距離表示と一致する。
- **10**：文字とアイコンの2要素選択で、右に行中心の整列操作を表示する。
- **12**：Coverを選択し、下のアニメーションからタイムラインを開く。作成ツールを閉じ、左の選択・右の対象・下のトラックをCoverに揃える。
- **11**：ヘッダーのプレビューから編集パネルを隠す。「編集に戻る」を左上に固定する。

画面内には遷移を説明する文章や矢印図を置かず、タブ、選択行、フォーカス枠、入力欄に隣接するポップオーバー、適用・キャンセルで状態を示す。

## 実際の共通定義

この文書は図形のコピーではなく、Nodiの `components` と `instance` を使う。

- ヘッダー、フッター、作成ツール、プレビュー操作
- ボタン、入力欄、参照フィールド、メニュー行、アイコン
- レイヤー行、選択行、レイヤー／アセットのタブ
- フレーム、インスタンス、複数選択のプロパティ群
- 作品カード、アセットのサムネイル、タイムライン

文言の違いはインスタンスの `overrides` に格納する。色は10段階のグレースケールパレットを参照し、フレームの余白と間隔は `Space / 0・4・8・12・16・20・24・32` を参照する。部品内とパネル内の並びは自動レイアウトで解決する。

画面の外形は左240px・中央900px・右300px、ヘッダー64px・ステータス32px。右パネルの入力は124pxの2列・列間12px。操作は36px高で統一する。

## 更新と検証

`build.mjs` がこのモックの生成元。共通部品や画面構成を変更した場合は次を実行する。

```bash
node designs/build.mjs
pnpm exec vitest run tests/design-documents.test.ts
```

直接 `.nodi` を編集した後に生成すると、その編集は置き換わるため、生成元にも変更を反映する。

`node designs/preview.mjs` で `.local/nodi-design-preview.html` を生成できる。現行アプリと同じ参照解決・自動レイアウトを通した確認用HTMLで、実アプリそのもののスクリーンショットではない。

テストでは保存と再読込、共通定義の利用、参照解決後の全画面の領域、シェルの一致を確認する。Nodi文書は編集可能な画面モックであり、描いたボタンに画面遷移処理は付いていない。実画面の目視確認は別途必要。
