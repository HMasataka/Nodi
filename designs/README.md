# Nodi のUIデザイン

`nodi.nodi` をNodiで開く。
メインの編集画面（1440×960px）をグレースケールで描き、左右のパネルを開いた状態、閉じた状態、タイムラインを開いた状態、ファイルメニューを開いた状態、アセットを開いた状態、外部変更のダイアログを開いた状態、エラーを表示した状態、幅を切り換えてプレビューした状態を並べている。
どの画面も同じ文書を開き、プレビュー以外の画面では同じカード（Project card）を選択している。
その下に、要素の種類ごとのプロパティ、「⋯」メニュー、アセットの色の「⋯」メニューを並べたシート（Inspector / 種類ごとの構成）、ダイアログとトーストを並べたシート（Dialog / 種類ごとの文言）、編集中にキャンバスへ重ねる表示を並べたシート（Canvas / 編集中の表示）、値を動かす入力を並べたシート（Controls / 値を動かす入力）を置いている。

## 画面の構成

- **パネル**：左にレイヤーとアセットを切り換えるパネル（240px）、右にプロパティ（280px）を置き、どちらも画面の上端から下端まで伸ばす。閉じるとキャンバスが画面全体に広がる。
- **ファイルのチップ**：キャンバスの左上に、開いているファイル名を角丸のチップで浮かせる。チップの先頭のボタンで左パネルを開閉し、ファイル名を押すとファイルメニューが開く。未保存の変更があるときは、ファイル名の直後に点を出す。
- **操作のチップ**：キャンバスの右上に、倍率とプレビューのアイコンを置く。プレビューのアイコンでプレビューに切り換える。末尾のボタンで右パネルを開閉する。
- **作成ツール**：キャンバスの下中央に浮かせる。末尾のボタンでタイムラインを開閉する。
- **タイムライン**：左右のパネルの間で、キャンバスの下端から228pxを占める。パネルは画面の上端から下端までの長さを保ち、キャンバスが縮む。作成ツールはタイムラインの12px上に移る。

二つのチップと作成ツールは、パネルやタイムラインを開閉してもキャンバスの端から12pxの位置を保つ。

## ファイルメニュー

ファイルメニューはファイルのチップの8px下に開き、次の順に並べる。

- ファイル名、保存場所、未保存の変更の有無
- 開く、保存
- SVG パスの取り込み
- 元に戻す、やり直す

ボタンを置かない操作も、ここにショートカットとともに並べて見つけられるようにする。
画像の追加は作成ツールから行い、PNG 書き出しは選択中のフレームに対する操作なのでプロパティの「⋯」メニューに置く。

## アセット

左パネルの「アセット」には、文書全体で共有する定義を、コンポーネント、色、余白の順に並べる。

- **節の見出し**：名前の直後に件数を置き、追加の操作を右端にそろえる。コンポーネントは選択中の要素の「⋯」メニューから作るので、見出しに追加の操作を置かない。色は取り込みと追加、余白は追加を置く。
- **コンポーネントの行**：選択中の行に、配置のボタンと「⋯」を出す。「⋯」メニューにはキャンバスに配置、名前を変更、複製、削除を並べ、パネルの中の節を隠さないようパネルの右隣に開く。インスタンスを選んでいるときは、その参照元の行を強調する。
- **色の行**：見本、名前、HEX を並べる。選んだ行の直下で HEX とアルファ（0〜255）を編集し、行の「⋯」メニューには名前を変更、複製、削除を並べる。
- **余白の行**：名前と px 値を並べる。

## キャンバスの上の表示

編集中にキャンバスへ重ねる表示は、次の約束でそろえる。

- 選択枠とガイドは、濃いグレーの1pxの線にする。
- つまみとパスの点は、白地に濃いグレーの枠の8px角にする。選んだパスの点だけ黒く塗る。
- ベジェのハンドルは、細い線の先に6pxの丸を付ける。
- 寸法と間隔は、濃い地に白い文字の札で出す。

場面ごとの表示は次のとおり。

| 場面 | 表示 |
|---|---|
| 範囲選択 | ドラッグした範囲を薄い地と枠で示し、掛かる要素に選択枠を出す |
| Shift で加算選択 | 個々の要素の選択枠と、まとめた範囲の枠、つまみ、寸法を出す |
| スナップと整列ガイド | そろった辺にガイドを引き、隣との間隔を札で出す |
| 楕円を描いている途中 | 外接する枠、つまみ、寸法を出す |
| ペンで描いている途中 | 置いた点、いま引いているハンドル、次の線分の見込みを出す |
| パスの点の編集 | 選んだ点を黒で示し、その点のハンドルだけを出す |
| マスク | 切り抜いた外側を薄く出し、レイヤーには「マスク」の札を付ける |
| 画像 | 角丸で切り抜いて描き、取り込んだ直後は選んだ状態にする |

## 値を動かす入力

- **グラデーション**：塗りの節で単色、線形、放射状を切り換える。塗りを外すときは節の「−」を使う。帯の下に色の位置を札で示し、選んだ札を黒く塗る。選んだ札の位置と色を帯の下で編集し、帯をクリックすると色の位置を足す。線形は始点と終点、放射状は中心と半径を入力する。
- **画像の色調整**：画像の節の「色調整」から開き、明るさ、コントラスト、彩度、グレースケール、セピア、色相をスライダーで調整する。既定値から変えた行だけ値を濃く出し、見出しの右端で既定値に戻す。
- **スクロールで動くアニメーション**：再生しないので、見出しには再生ボタンの代わりにスクロールの進み具合を割合で出し、再生位置の線を進み具合のつまみとして動かす。

## プレビュー

プレビューでは、選択中のフレームを指定した幅で描く。

- 幅の切り換えはキャンバスの上中央に浮かべ、320、390、768、1024、1440 の切り換えと幅の入力欄を置く。末尾のボタンで編集に戻る。
- 編集はしないので、選択枠と作成ツールを出さない。
- 操作のチップのプレビューのアイコンは、プレビュー中は押された状態にする。

PNG 書き出しは、選択中のフレームの「⋯」メニューから行う。

## ダイアログとトースト

確認と復元のダイアログは、共通の形にする。

- 画面全体を幕で覆い、画面の中央に開く。
- 見出し、本文、必要ならファイルの場所、操作の行の順に並べる。
- 主となる操作は黒地のボタンにして右端に置き、取り消す操作をその左に置く。

ダイアログは次の4つである。

| ダイアログ | 出る場面 | 操作 |
|---|---|---|
| ファイルが外部で更新されました | 未保存の変更があるときに、開いているファイルが外部で書き換わった | 今の内容を残す、再読み込み |
| 未保存の変更があります | 未保存の変更があるときに、別のドキュメントを開こうとした | キャンセル、破棄して開く |
| 未保存の編集が見つかりました | 前回の異常終了時の編集内容が残っていた | 破棄して開始、編集を復元 |
| 復元データを読み取れません | 残っていた編集内容を読み取れなかった | 破棄して開始 |

エラーはトーストで知らせる。
トーストは地を暗くしてキャンバスと区別し、作成ツールと重ならないようキャンバスの右下の角から12pxの位置に付ける。

## タイムラインを開く動線

タイムラインは二つの入口から開く。

- 作成ツールの末尾のボタン。選択中の要素の最初のアニメーションを開く。
- プロパティの「アニメーション」に並ぶ行。押した行のアニメーションを開く。「＋」で追加したアニメーションもタイムラインで開く。

タイムラインには、アニメーションの切り換えと追加と削除、トリガー、長さ、遅延、繰り返し、再生と現在時刻、プロパティごとのトラック、選んだキーフレームの時刻、値、イージング、再生位置へのキーフレームの追加と削除を並べる。
アニメーションの設定はタイムラインにまとめ、プロパティにはアニメーションの一覧だけを置く。
アプリ名はどこにも出さない。
元に戻す、やり直す、保存はショートカットで操作するので、UIには置かない。

## プロパティの骨組み

プロパティは、要素の種類によらず次の順に並べる。

1. 見出し：種類、名前、「⋯」メニュー
2. 位置とサイズ：X、Y、W、H、幅と高さのサイズモード、回転、不透明度
3. 種類ごとの節：フレームは自動レイアウトとはみ出し、テキストは書体と文字組みと選択範囲の装飾、画像はフィットと焦点と色調整、矩形と楕円はマスク、パスは点の編集と塗りの規則、インスタンスは参照元と上書き
4. 見た目の節：塗り（テキストは文字色）、線、角丸。種類が持たない節は出さない
5. 効果：影、全体ぼかし
6. アニメーション：アニメーションの一覧。設定はタイムラインで行う

節の見出しの記号で、節の性質を区別する。

- **記号なし**：常にある節。位置とサイズ、種類ごとの節、角丸
- **＋と−**：一つだけ持てる節。未設定なら「＋」で追加し、設定済みなら「−」で外す。塗り、線
- **常に＋**：複数持てる節。効果、アニメーション

複製、削除、名前の変更、重ね順、コンポーネントの作成、PNG 書き出し、ID のコピーは、見出しの「⋯」メニューにまとめる。
編集のたびには使わない操作を、プロパティの列から外すためである。

## 共通の約束

色は10段階のグレースケールパレットを参照する。
フレームの余白と間隔は `Space / 0・4・8・12・16・20・24・32` を参照する。
アイコンボタンは32px高、入力欄は28px高、レイヤー行は28px高にしている。

パネル、チップ、作成ツール、アートボード、カード、入力欄、アイコンボタンは `components` に定義し、`instance` で使う。
文言の違いはインスタンスの `overrides` に格納する。

## 更新と検証

`build.mjs` がこのモックの生成元。
`.nodi` を直接編集してから生成すると、その編集は置き換わるため、生成元にも変更を反映する。

```bash
node designs/build.mjs
pnpm exec vitest run tests/design-documents.test.ts
```

`node designs/preview.mjs` で `.local/nodi-design-preview.html` を生成できる。
現行アプリと同じ参照解決と自動レイアウトを通した確認用HTMLで、実アプリのスクリーンショットではない。

テストでは、保存と再読込、共通定義の利用、選択枠がカードと一致すること、チップがキャンバスの角に付くこと、タイムラインがパネルの間のキャンバス下端を占めること、ファイルメニューがチップの直下に開くこと、アセットの節の順とメニューの位置、ダイアログが画面の中央に開き主となる操作を右端に置くこと、トーストがキャンバスの右下の角に付くこと、プレビューで幅の切り換えが上中央に付きフレームを指定の幅で描くこと、キャンバスの上のつまみ・点・ガイドの大きさと色がそろうこと、スライダーとグラデーションの色の位置が同じ形であること、プロパティが全種類で共通の節を同じ順に並べること、子要素が親の領域からはみ出さないことを確認する。
