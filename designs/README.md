# Nodi のUIデザイン

`nodi.nodi` をNodiで開く。グレースケール見本と、同じエディタの3状態を横に並べている。

- **Nodi / グレースケール**：10色の色見本。名前とHEX値で参照する。
- **Nodi / エディタ — フレーム選択**：1440×960pxのコア画面案。カードのフレームを選択して編集している状態。
- **Nodi / アニメーション編集 — CoverのFade in**：レイヤーとキャンバスを残してタイムラインを開いた状態。親カードでなく子のCoverを選択し、同じCoverのFade inとHover liftを切り替えられる。
- **Nodi / 全画面プレビュー — 検証幅1440・表示80%**：左右の編集パネルを隠し、画面の全幅をプレビューに使う。1440×840のページを80%の1152×672で表示している。

この文書は編集可能なデザインモック。ボタンや入力欄はNodiの図形・テキストで表現しているため、描かれた操作をクリックしてもアプリの機能は実行しない。フレーム選択後にPNGへ書き出せる。

## 情報設計

「作る → 階層から選ぶ → 値を調整する → 保存」を中心に一画面で行う。PNG書き出しは共有や最終確認のための補助操作として扱う。

| 領域 | 配置する機能 | 狙い |
| --- | --- | --- |
| 上部64px | 文書名、保存状態、ファイルメニュー、プレビュー、Undo/Redo、保存 | 文書単位の操作を固定する |
| 左240px | レイヤー階層、選択状態、要素操作メニュー | 名前と親子関係から目的の要素を選ぶ |
| 中央900px | キャンバス、選択階層、ズーム、選択枠と寸法 | 編集対象を主役にする |
| 中央下部 | 選択、フレーム、図形、ペン、文字、取り込み | 作成操作を短いツール列に集める |
| 右300px | 名前、位置・サイズ・サイズモード、レイアウト、見た目、効果、要素の詳細、書き出しメニュー | 選択要素の設定を作業順に並べる |
| 下部32px | 選択数、アニメーションの入口 | 通常はタイムラインを閉じ、キャンバスの面積を確保する |

## 既存機能の整理

- **開く・保存・復元**：開くは左上のファイルメニュー、保存は右上に常設。復元は起動時のダイアログで扱う。
- **矩形・楕円**：図形ツール内で種類を選択。追加と描画を別々の常設ボタンにしない。
- **画像・SVGパス**：「取り込む」メニューで画像としての追加と編集可能なパスへの変換を選ぶ。
- **複製・削除・重なり順**：右の要素名横のメニューとレイヤーのコンテキストメニューへまとめる。破壊的操作を常設の主ボタンにしない。
- **複数選択の整列**：複数選択時だけ右パネル上部に出す。
- **フレーム**：自由・縦・横のレイアウト、間隔、余白、整列、クリップ。詳細な四辺の余白や主軸配置は展開して編集する。
- **サイズモード**：幅と高さの入力欄の直下に124px幅のセレクトを置く。固定・伸縮・内容の選択肢も同じ幅を基本にする。最小・最大は「制約」から必要時に展開する。独立した大きなカードにはしない。
- **プレビュー**：上部から全画面の表示状態へ移る。「検証幅」はレイアウト計算の幅、「全体表示／実寸」は表示倍率として別操作にする。検証幅1440でも全体表示なら縮小して全体を見られる。実寸100%では足りない領域をスクロールして確認する。編集パネルは表示しない。「編集に戻る」で元の要素選択・編集モード・タイムライン・表示位置へ戻る。
- **アニメーション**：同じエディタの下部へタイムラインを開く。左レイヤー・中央キャンバスから子を含む別要素を選択でき、通常編集へ戻る必要はない。右には選択要素名と、その要素に付いたアニメーション一覧・追加操作を表示する。アニメーションを選ぶと下部のトラック・タイミングが切り替わる。キーフレームを選ぶと下段で時刻・値・緩急を編集する。作成ツール列はこの状態では隠し、点や図形の新規作成へ戻るときだけタイムラインを閉じる。
- **見た目**：塗り、線、角丸、不透明度。色見本から単色・線形・放射状とアルファの詳細を開く。辺線は矩形・フレームの線設定から展開する。
- **影・ぼかし**：「効果」を展開して設定する。
- **テキスト**：文字選択時は右パネルに本文・範囲装飾・フォント・太さ・サイズ・行高・字間・揃えを表示する。
- **画像**：画像選択時はフィット・焦点・角丸・色調整を表示する。
- **パス**：点とハンドルはキャンバスに、塗り規則・点の挿入／削除・直線／曲線切り替えは右パネルに表示する。
- **マスク**：矩形・楕円選択時に利用でき、レイヤー行にもマスク状態を表示する。
- **要素ID**：「要素の詳細」に収納する。MCPからの識別に使うが、通常の編集では名前を優先する。
- **書き出し**：右パネルの小さな入口から160〜180px幅のメニューでPNGまたはCSSを選ぶ。時刻やスクロール進行度の設定はPNGを選んだ後にだけ表示する。最初のメニューへ設定欄を全部並べない。常時の枠線や背景は付けず、32px高のクリック領域とホバー・フォーカス表示を確保する。

## アニメーションの編集動線

1. 例として、ページ表示時に画像をフェードインさせたい場合は、左レイヤーの `Project card > Cover` を選ぶ。
2. 下部の「アニメーション」からタイムラインを開き、「アニメーションを追加」。新規時は名前、開始条件、動かす属性を選ぶ。
3. `Fade in` に「読み込み」「不透明度」「0% → 100%」「800ms」を設定する。タイムラインで中間のキーフレームやイージングを調整する。
4. 同じ画像をホバー時に少し上げたい場合は、右の一覧からさらに追加して `Hover lift` を作る。「ホバー」「Y」「現在位置 → 8px上」を設定する。既存のFade inは置き換えず、別の動きとして並ぶ。
5. 文字にも動きを付ける場合は、左の `Title` を選ぶ。タイムラインを開いたまま対象と一覧が切り替わる。親Project cardを選べば、カード全体への動きを編集できる。
6. 「プレビュー」でページ全体に対して再生・ホバー・クリックを確認する。スクロールトリガーがある場合だけ進行度の操作を表示する。

「要素の選択」は左レイヤーとキャンバス、「動きの選択」は右の名前付き一覧、「キーフレームの選択」は下部タイムラインで示す。開始条件の4項目はタイミング設定内の小さなセレクトで扱い、別画面へ移動しない。

## 見た目の方針

- 色はグレースケール見本の10色だけ。白い操作面、Gray 100のキャンバス、Gray 200の選択行、Gray 800のアクティブツールを使う。
- 余白は8px単位を基本にする。入力欄は32px、操作ボタンは34〜40px。
- 線は区切りと選択状態に使い、全要素をカードで囲まない。
- 色の違いに頼らず、選択行のマーカー・太字・キャンバス枠で選択状態を伝える。
- 開閉メニュー、折りたたみ、ツール列への統合は今回のUI提案。現行アプリへは別途実装する。
- 無限キャンバスは中央の操作として扱い、余白や移動操作を説明する常設テキストは置かない。
- パレットの参照機能や共同編集・オンライン共有は含めない。CSS書き出しは既存機能の再配置案。

## 修正を重ねて決めたルール

- 文書名の後ろの空テキスト領域を余白として使わない。保存状態との間隔は8px。
- ヘッダー操作は36px高・8px間隔。プレビューと履歴操作の間だけ16px空けて用途を分ける。
- 右パネルは左右20px、2列の幅は各124px、列間12px。モード欄を含めて同じ列を使う。
- タブは内側余白4pxで等幅に分割し、ラベルを個別の中央配置にする。
- ラベルと値、ラベルとアイコンは別要素。空白文字で整列させない。
- アイコンは文字記号で代用せずパスまたは図形を使う。線幅は原則1.5px。
- テキストの2px内側余白と行高から行中央を求め、アイコン中央と一致させる。12px文字の操作ラベルは行高16px、テキスト枠20pxを基本にする。
- レイヤーの行間隔は36px。最上位フレームだけ大きな間隔を入れない。
- PNGやCSS書き出しは補助操作。大きな常設ボタンにせず、上の項目との余白は16px程度に抑える。
- 操作方法や単位を説明する常設文言は追加しない。状態を表す数値・設定項目名のみ表示する。
