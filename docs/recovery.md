# 保存の安全性と未保存内容の復元

`.nodi` の保存は、同じファイルシステム上の一時ファイルへ全内容を書いて同期してから、保存先を原子的に置き換える。書き込み途中で失敗した場合、既存のファイルはそのまま残る。

デスクトップアプリで未保存の編集がある間は、アプリの設定ディレクトリに復元データを別ファイルとして退避する。確定した編集ごとに退避し、保存済み状態に戻った場合は削除する。ドラッグ中など未確定のプレビューは退避しない。復元データには文書のスナップショットと元のファイルパスを記録するが、Undo / Redo の履歴やリビジョン ID は保存しない。

異常終了後に復元データが残っていれば、次回の起動時に「編集を復元」または「破棄して開始」を選べる。復元すると新しい未保存文書として開くため、保存時には保存先を選び直す。元の `.nodi` ファイルは自動では上書きしない。破損した復元データは勝手に消さず、エラーを表示して明示的な破棄を待つ。正常終了時は復元データを削除する。

復元データは `.nodi` の保存形式とは別で、起動中の履歴を永続化するものではない。ブラウザ上の `pnpm dev` ではデスクトップ用の退避・復元は動作しない。
