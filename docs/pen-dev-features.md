# pen.dev 機能調査

調査日: 2026-10-28

Nodi の開発に向けて、pen.dev の公開サイトと公式ドキュメントに記載された機能を整理する。以下の「提供機能」は pen.dev の説明に基づく。「Nodi への示唆」は開発上の提案であり、pen.dev の公式な開発方針ではない。

## 製品の位置づけ

pen.dev は、デザインの作成・編集を人と AI エージェントが同じキャンバス上で行うベクターデザインツール。デスクトップアプリ、IDE 拡張、CLI を提供し、外部エージェントは MCP 経由で接続できる。

## 提供機能

### キャンバスと基本編集

- 無限キャンバスのパン・ズーム、選択範囲へのズーム、複数選択、階層内の直接選択。
- レイヤーパネルで階層の閲覧、並べ替え、移動、名前変更、表示・非表示を操作。プロパティパネルで寸法、配置、見た目を編集。
- フレームとグループ、クリッピング、オブジェクト・ピクセルへのスナップ、要素間距離の表示、Undo/Redo、ショートカット。
- 大量レイヤーを扱うための WebGL ベースの描画パイプラインを訴求。

### 描画とレイアウト

- 矩形、楕円、多角形、ペンツールによるパス、テキスト、画像、アイコンを配置。SVG は編集可能なレイヤーとして扱える。
- テキストのフォント・サイズ・行間・字間・配置、テキストボックスの自動幅・自動高さ・固定サイズを設定。カスタムフォントも取り込み可能。
- Flex 型レイアウトで横・縦方向、Gap、Padding、整列を設定。固定サイズ、内容に合わせる Hug、親を埋める Fill、子要素の絶対配置に対応。
- 選択範囲の拡大縮小では、文字、線、角丸、余白、エフェクトも合わせてスケール。

### スタイルと画像

- 色、画像、線形・放射・角度・メッシュグラデーション、複数の塗り、線、透明度、ブレンドモード。
- ドロップシャドウ、インナーシャドウ、レイヤーぼかし、背景ぼかし、シェーダーによる塗り・エフェクト。
- マスク、画像のクロップ、背景除去、ラスター画像のベクター化。背景除去とベクター化にはサインインとインターネット接続が必要。
- Material Symbols、Lucide、Feather、Phosphor などのアイコンライブラリ。

### 再利用とデザインシステム

- コンポーネントの定義とインスタンス化、インスタンスごとのプロパティや子要素の上書き、コンポーネントの入れ子。
- インスタンスごとに内容を差し込めるスロット。ファイル間で共有するデザインライブラリ。
- 色や数値などの変数、テーマに応じた変数値の切り替え。CSS 変数との対応付けはエージェントに依頼できる。

### AI と開発者向けの操作

- デスクトップアプリ内のチャットからデザインを新規作成・修正。選択レイヤーや添付画像・ファイルを文脈として渡せる。
- モデル選択、会話セッション、スキル、複数エージェントでの分担・案の比較、レイアウトやスタイルの派生案生成。
- 外部 AI クライアントは MCP で実行中のアプリ・IDE ホストへ接続し、ドキュメントの参照や編集を行う。CLI からの操作にも対応。
- Script ノードは外部の JavaScript ファイルからレイヤーを生成し、サイズや入力値を変えると再描画する。生成結果を通常の編集可能なレイヤーに変換できる。

### 取り込み、書き出し、共有

- Figma ファイルや要素、PNG・JPEG・SVG を取り込み。内蔵ブラウザや Chrome 拡張を介し、Web ページを編集可能なレイヤーとして取り込める。ページ全体・個別要素のスクリーンショットにも対応。
- レイヤーを PNG・JPEG・WEBP・PDF で書き出し。選択要素を HTML＋CSS または HTML＋Tailwind として出力できる。
- デザインからコード、既存コードからデザインをエージェントに依頼できる。両者は常時自動同期ではなく、依頼・確認を繰り返すワークフロー。Web 取り込み後のレイヤーには元ページの JavaScript インタラクションは残らない。
- JSON ベースの `.pen` ファイルをプロジェクト内で保存し、Git で管理可能。共有リンクは閲覧・ダウンロード用のスナップショットで、変更後には更新操作が必要。
- スライドの作成、整理、プレゼンテーションモードにも対応。

## Nodi への示唆

最初の実装範囲は、以下の順で積み上げると手動操作とエージェント操作が同じデータ・コマンドを共有できる。

1. ID と親子関係を持つレイヤーツリー、保存・読み込み可能なドキュメント形式。
2. キャンバスのパン・ズーム、選択、移動、サイズ変更、レイヤーパネル、基本図形とテキスト。
3. プロパティ編集、フレーム内レイアウト、Undo/Redo、画像・SVG の入出力。
4. 同じ編集操作を呼び出せる外部 API とエージェント連携。
5. コンポーネント、変数、ブラウザ取り込み、コード書き出しなどを必要性に応じて拡張。

この順序は機能間の依存を踏まえた提案であり、pen.dev の優先順位を示すものではない。
