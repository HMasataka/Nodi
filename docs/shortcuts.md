# キーボードショートカット

編集画面のショートカットの割り当てを記録する。
判定は `src/pages/editor/shortcuts.ts`、実行は `src/pages/editor/hooks/useEditorShortcuts.ts` が担う。

## 修飾キー

macOS では ⌘、Windows・Linux では Ctrl を主の修飾キーにする。
表では macOS の表記で書き、Windows・Linux では ⌘ を Ctrl、⇧ を Shift に読み替える。

主の修飾キーと Shift・Alt の組み合わせが割り当てと完全に一致したときだけ動かす。
たとえば ⌘ と Ctrl を同時に押したときや、Alt を足したときは何もしない。

## 入力中の扱い

テキストや数値の入力欄、テキストエリア、contenteditable の要素にフォーカスがあるときは、文字入力を奪わない。

- 元に戻す・やり直すは、入力欄の取り消しとやり直しを優先し、文書の履歴を動かさない。
- 保存・開くは入力中でも動かす。入力欄は blur で値を確定するため、先に blur して下書きを確定してから実行する。
- それ以外のショートカットは入力中は動かさない。Delete や矢印キーは入力欄の中の操作になる。

チェックボックス、スライダー、ボタンは入力中とみなさない。

## 割り当て

| 分類 | 操作 | キー | 入力中 |
| --- | --- | --- | --- |
| ファイル | 保存 | ⌘S | 動かす |
| ファイル | 開く | ⌘O | 動かす |
| 編集 | 元に戻す | ⌘Z | 入力欄に任せる |
| 編集 | やり直す | ⇧⌘Z（Windows・Linux では Ctrl+Y も） | 入力欄に任せる |
| 編集 | 削除 | Delete / Backspace | 入力欄に任せる |
| 編集 | 複製 | ⌘D | 入力欄に任せる |
| 編集 | すべて選択 | ⌘A | 入力欄に任せる |
| 編集 | 選択の解除 | Esc | 入力欄に任せる |
| 編集 | 選択中の要素を 1px 動かす | ← → ↑ ↓ | 入力欄に任せる |
| 編集 | 選択中の要素を 10px 動かす | ⇧ と ← → ↑ ↓ | 入力欄に任せる |
| 作成ツール | 選択 | V | 入力欄に任せる |
| 作成ツール | フレーム | F | 入力欄に任せる |
| 作成ツール | 矩形 | R | 入力欄に任せる |
| 作成ツール | 楕円 | O | 入力欄に任せる |
| 作成ツール | ペン | P | 入力欄に任せる |
| 作成ツール | テキスト | T | 入力欄に任せる |
| 重ね順 | 前面へ | ⌘] | 入力欄に任せる |
| 重ね順 | 背面へ | ⌘[ | 入力欄に任せる |
| 重ね順 | 最前面へ | ⌥⌘] | 入力欄に任せる |
| 重ね順 | 最背面へ | ⌥⌘[ | 入力欄に任せる |
| 表示 | 拡大 | ⌘+（⌘= でも可） | 入力欄に任せる |
| 表示 | 縮小 | ⌘- | 入力欄に任せる |
| 表示 | 100% | ⇧0 | 入力欄に任せる |
| 表示 | 全体を表示 | ⇧1 | 入力欄に任せる |
| パネル | 左パネルの開閉 | ⌥⌘1 | 入力欄に任せる |
| パネル | 右パネルの開閉 | ⌥⌘2 | 入力欄に任せる |
| パネル | タイムラインの開閉 | ⌥⌘3 | 入力欄に任せる |
| 表示 | プレビューの切り換え | ⌥⌘P | 入力欄に任せる |
| テキスト | 選択範囲の太字 | ⌘B | 本文の入力欄でだけ動かす |
| テキスト | 選択範囲の下線 | ⌘U | 本文の入力欄でだけ動かす |

- すべて選択は、選択中の要素と同じ親の子をすべて選ぶ。何も選んでいないときは最上位の要素を選ぶ。
- Esc は、作成ツールを選んでいるときは選択ツールに戻し、選択ツールのときは選択を外す。描画中・ペンの入力中・範囲選択中は、下の「キャンバスの操作」の取り消しを先に行う。
- 選択していないときの Delete や矢印キーは何もせず、キーの既定の動作（スクロールなど）を止めない。
- 拡大・縮小は画面の中心を保つ。1回で 1.25 倍ずつ変える。全体を表示は、最上位の要素をすべて 32px ずつの余白付きで画面に収める。
- プレビューの切り換えは、フレームを選んでいるときだけプレビューに入る。プレビュー中は Esc でも編集に戻る。
- 太字・下線は、プロパティのテキストの節の本文の入力欄で文字を選んでいるときに、その範囲へ掛ける。選んでいないときは何もしない。
- ⌥ を伴うショートカット（最前面へ・最背面へ・パネルの開閉・プレビューの切り換え）は、⌥ で入力される文字が変わるため物理キーの位置で判定する。位置は US 配列のキーで表記している。

## キャンバスの操作

ショートカットの判定とは別に、キャンバスが直接受けるキー操作がある。

| 操作 | キー |
| --- | --- |
| 描画・ペン・点の移動・範囲選択の取り消し | Esc |
| ペンの確定 | Enter |
| パン | Space を押しながらドラッグ |
| ズーム | ⌘ または Ctrl を押しながらホイール |
