# 複数要素の選択と一括操作

キャンバスやレイヤー一覧の要素を Shift クリックすると、現在の選択へ追加・解除できる。キャンバスの空白からドラッグすると選択範囲を描き、その範囲に重なる要素をまとめて選ぶ。Shift を押したまま範囲を描くと、既存の選択に追加する。

複数選択した要素のいずれかをドラッグすると、一括で移動する。プロパティの「選択中を削除」でまとめて削除できる。異なるフレーム内の要素も、同じドキュメント座標の移動量を各要素の親基準位置へ適用する。親フレームと子が同時に選ばれた場合、子が二重に移動することはない。

選択範囲の表示と選択状態は保存せず、編集履歴にも入れない。移動・削除はそれぞれ1操作として履歴へ記録し、Undo / Redo や `.nodi` の保存・再読込に反映される。

移動・右下のハンドルによるリサイズでは、周囲の要素の辺と中心へ近づくとスナップし、整列位置のガイドを表示する。プロパティの「選択要素の整列」から、複数要素を左・横中央・右、上・縦中央・下に揃えられる。計算はフレーム階層を含むドキュメント座標で行い、ガイドの表示だけでは履歴や未保存状態を変えない。
