# Nodi サンプル

`studio.nodi` は複数の最上位フレームを持つ編集用サンプル。先頭の「Studio / ホームページ」は、架空のデザインスタジオ「ATLAS STUDIO」の幅1440pxのトップページです。ナビゲーション、ヒーロー、取引先の帯、サービス、作品、実績の数字、問い合わせ、フッターを縦の自動レイアウトで積み、セクションごとに次の機能を使っています。

- 自動レイアウト：各セクションは幅を「親に合わせる」にしているので、プレビューで幅を 1024 などに切り換えると横並びのカードや列が伸び縮みする。
- 共通余白：セクションの余白（80）、列の間隔（24）、カードの内側（32）・行間（16）を共通値として参照する。
- パレット：背景・面・本文・補足・アクセント・紫を定義し、文字や塗りが参照する。アクセントを変えると見出しの「moves」やボタンなどがまとめて変わる。
- コンポーネント：ナビゲーション・ヒーロー・問い合わせのボタンは「共通ボタン」のインスタンスで、文言・幅・塗り・文字色だけをオーバーライドしている。
- 部分装飾：見出しの「moves」の色、説明文の「ATLAS STUDIO」の太字、「すべての作品を見る」とメールアドレスの下線は、一つのテキスト内の装飾範囲。
- 塗りと効果：ヒーロー背景の放射状グラデーション、問い合わせとサービスアイコンの線形グラデーション、モックアップの影と回転、辺線（ナビゲーション下・セクション境界・実績の区切り）。
- パス・マスク・画像：ロゴマークときらめき、サービスのアイコンは編集できるパス。中央のモックアップのアバターは丸いマスクで切り抜いた画像。作品の画像には彩度・コントラスト・色相の補正と焦点を設定している。
- アニメーション：ショーケースのモックアップとラベルは読み込み時に下からフェードイン、中央のモックアップとサービスのカードはホバーで浮き上がり、きらめきは回転し、取引先の名前はスクロールで横に流れる。タイムラインで再生し、スクロールのトリガーは再生位置の線で進み具合を動かして確かめる。読み込みのアニメーションには遅延を付けてあるので、再生前の静止状態は完成形のまま編集できる。

ホームページの右に並ぶ「Studio / 色と視覚効果」は960×680pxの検証用フレーム。8桁HEXの半透明色（塗り・線・辺線・部分装飾）、線形・放射状グラデーション、重なった子を持つフレームの不透明度、透過SVG画像と文字の外側影、マスクと影を組み合わせたフレーム全体のぼかしを6つのカードに配置しています。放射状グラデーションのカードには、穴のある編集可能な星形パスも置いています。

`github-docs-hello-world.nodi` は [GitHub Docs の Hello World ページ](https://docs.github.com/en/get-started/start-your-journey/hello-world) の冒頭から「Step 1: Create a repository」までを、幅1440pxのデスクトップ表示でトレースしたサンプル。2026年11月時点の表示を参考に、案内帯、ヘッダー、パンくず、左右のナビゲーション、記事本文と手順の図を再現しています。GitHub マークのみ埋め込み SVG 画像で、文字や罫線、ボタン、選択状態、手順の図は編集可能な Nodi の要素です。本文中のリンク色・下線、太字、インラインコードは一つのテキスト要素内の装飾範囲で表現しています。専用アイコンなど、現在の文書形式にない表現は近似しています。

「Studio / コンポーネント」は共通コンポーネントの定義とインスタンスを示すフレーム。左側サイドバーの「コンポーネント」に「共通ボタン」「共通カード」の定義が並び、キャンバス上には同じ定義を参照する複数のインスタンスを置いています。「保存ボタン」「キャンセルボタン」は同じ「共通ボタン」を参照しつつ、文言だけをオーバーライドしています。定義の見た目（背景・角丸・文字スタイル）を変えると、参照するインスタンスへ一括反映されます。インスタンスを選ぶと、プロパティの「オーバーライド」で文言を編集でき、「切り離す」でその時点の表示のまま通常の要素へ変換できます。

`path-icon.svg` は2つのパスで作った取り込み用アイコン。ツールバーの「SVGパスを取り込む」から選ぶと、透明なフレーム内に編集可能なパス2個として追加される。通常の「画像を追加」を選んだ場合は、従来どおり埋め込み画像になる。取り込みは `viewBox` と単色の `<path>` に限定し、楕円弧、基本図形、transform、CSS、外部参照などを含むSVGは理由を表示して拒否する。

## 試し方

キャンバスはホイール／トラックパッドで上下左右に移動できる。Shift＋縦ホイールは横移動、⌘/Ctrl＋ホイールとピンチはポインタ位置を基準にズームする。Space＋ドラッグまたは中ボタンドラッグでも移動でき、文書原点の左・上にも端なくパンできる。要素やパスの点をドラッグ中はホイールによる表示移動を止める。文書を開く／復元すると最初の最上位フレームを余白付きで中央表示し、空文書は原点の周囲に余白を置く。表示位置は保存・Undoの対象外。

1. `pnpm tauri dev` でアプリを起動し、「開く」から `samples/studio.nodi` を選ぶ。
2. 「Studio / ホームページ」を選び、操作のチップの目のアイコン（⌥⌘P）でプレビューにする。上の幅の切り換えで 1440・1024 などを選び、自動レイアウトで伸び縮みする様子を確かめる。Esc で編集に戻る。
3. テキストの本文編集、要素の移動・サイズ変更・塗りや線の変更、複製・削除、Undo / Redo、キャンバスのパン・ズームを試す。矩形・楕円の描画ツールはドラッグ、ペンツールはクリックで点を追加して新しい図形を描ける。最初の点をクリックすると輪郭を閉じ、Enter またはダブルクリックで開いた線として確定する。Esc で描画をキャンセルできる。
4. 保存するとこのサンプルファイルが上書きされる。元のサンプルを残す場合は、編集前にファイルをコピーしてそちらを開く。
5. 最上位の「Studio / ホームページ」を選び、プロパティの「PNG に書き出す」で編集 UI を含まない画像を確認する。

視覚効果を試すには、同じ `studio.nodi` のレイヤー一覧から「Studio / 色と視覚効果」を選んで PNG に書き出す。各カードのレイヤーで塗りや効果を編集し、編集画面とPNGを並べて確認できる。放射状グラデーションのカードにある星形パスを選ぶと、アンカーと曲線ハンドルのドラッグや、プロパティからの点の挿入・削除を試せる。影とぼかしの順序は右下のカード、透明画像のシルエットに沿う影は下中央のカードで確認する。

左サイドバーのパレット一覧で色を変えると「Studio / ホームページ」の参照先へ反映され、塗り・線・文字などの色入力の「パレット」で直接指定と参照を切り替えられる。

GitHub Docs のトレースは「開く」から `samples/github-docs-hello-world.nodi` を選ぶ。最上位の「GitHub Docs / Hello World · 1440×2030」を選ぶと PNG に書き出せます。書き出した PNG を元ページと並べて、文字組みやアイコンなど再現できていない箇所を確認できます。
「Step 1 / 文中の参考リンク」を選択し、プロパティの本文欄で文字を範囲選択すると、下のボタンで太字・下線・コードを付け外しできます。文字色の変更と解除も同じ選択範囲に適用されます。

## 更新ルール

新しい描画要素・スタイル・保存項目を追加する PR では、このサンプルを新機能が分かる内容に更新する。`pnpm test` は `samples/*.nodi` を現行の保存形式で読み込めるか確認する。サンプルの ID は説明や比較で参照しやすいよう、既存要素では維持する。
