# Nodi サンプル

`studio.nodi` はフレーム・矩形・楕円・テキスト・埋め込み画像を使った、ダッシュボード風の編集用サンプル。`ATLAS STUDIO` と `Overview` はシステムフォント・太さ・行高・字間を指定し、説明文は従来の標準フォントで表示します。要素名はキャンバス上に描かず、レイヤー一覧とプロパティで確認できます。

`github-docs-hello-world.nodi` は [GitHub Docs の Hello World ページ](https://docs.github.com/en/get-started/start-your-journey/hello-world) の冒頭から「Step 1: Create a repository」までを、幅1440pxのデスクトップ表示でトレースしたサンプル。2026年11月時点の表示を参考に、案内帯、ヘッダー、パンくず、左右のナビゲーション、記事本文と手順の図を再現しています。GitHub マークのみ埋め込み SVG 画像で、文字や罫線、ボタン、選択状態、手順の図は編集可能な Nodi の要素です。見出しの行高・字間と本文の行間を調整しています。下線・専用アイコンなど、現在の文書形式にない表現は近似しています。

## 試し方

1. `pnpm tauri dev` でアプリを起動し、「開く」から `samples/studio.nodi` を選ぶ。
2. レイヤーの階層をたどり、同名の「カード」をそれぞれ選択する。プロパティに異なる ID が表示される。
3. テキストの本文編集、要素の移動・サイズ変更・塗りや線の変更、複製・削除、Undo / Redo、キャンバスのパン・ズームを試す。矩形・楕円の描画ツールを選ぶとドラッグで新しい図形を描ける。Esc で描画をキャンセルできる。
4. 保存するとこのサンプルファイルが上書きされる。元のサンプルを残す場合は、編集前にファイルをコピーしてそちらを開く。
5. 最上位の「Studio / デスクトップ」を選び、プロパティの「PNG に書き出す」で編集 UI を含まない画像を確認する。

GitHub Docs のトレースは「開く」から `samples/github-docs-hello-world.nodi` を選ぶ。最上位の「GitHub Docs / Hello World · 1440×2030」を選ぶと PNG に書き出せます。書き出した PNG を元ページと並べて、文字組みやアイコンなど再現できていない箇所を確認できます。

## 更新ルール

新しい描画要素・スタイル・保存項目を追加する PR では、このサンプルを新機能が分かる内容に更新する。`pnpm test` は `samples/*.nodi` を現行の保存形式で読み込めるか確認する。サンプルの ID は説明や比較で参照しやすいよう、既存要素では維持する。
